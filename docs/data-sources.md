# Data sources

Every value shown in the app carries one of these labels. Sources are kept separate and never merged into one training table.

| Label | Dataset | What we use it for | Licence / terms |
| --- | --- | --- | --- |
| general human data (PhysioNet) | [A Multi-Night Instantaneous Heart Rate and Accelerometry Dataset with EEG Sleep Stage Labels v1.0.1](https://physionet.org/content/bidsleep-dataset/1.0.1/): 47 healthy adults on Earth, 253 nights | Nightly resting heart-rate and sleep baseline model | ODC-By 1.0, cite it |
| NASA | NASA OSDR Inspiration4 bloodwork, OSD-569 (CBC) and OSD-575 (CMP, incl. glucose): 4 civilian crew, 7 draws | Changes from each person's preflight levels | NASA open data |
| environment | NASA OSDR Environmental Data App, Rodent Research-1 (ISS, 2014): radiation dose, cabin temperature, humidity, CO2 | Station environment context, not a crew member's personal dose | NASA open data |
| general human data (Body performance) | [Body performance data](https://www.kaggle.com/datasets/kukuroo3/body-performance-data) (Korea Sports Promotion Foundation, via Kaggle): 13,393 adults aged 21-64 | Age- and sex-specific fitness percentiles (grip, broad jump, sit-ups) for the preflight muscle baseline | Check the Kaggle page before submitting |
| synthetic | Generated by our scripts | Blood pressure, body temperature, mood, SpO2 and live demo streams | Ours |

## Datasets we checked and did not train on

| Dataset | Why not |
| --- | --- |
| Human Vital Signs Dataset 2024 (Kaggle, 200,020 rows) | Synthetic. One reading per person, so no personal baseline is possible. Values are uniform within normal ranges with no correlation between vitals, and the risk label mostly follows one rule (heart rate > 90). A model would only learn that rule. |
| Sleep Health and Lifestyle Dataset (Kaggle, 374 rows) | Synthetic, and 242 of the 374 rows are duplicates. |
